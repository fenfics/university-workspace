# Personal Income Tax Calculator

A Java Swing desktop application for calculating personal income tax based on user income and deductions. The application provides a step-by-step interface for entering tax information, calculating tax liability, managing tax records, and visualizing tax data.

## Features

- User authentication system
- PIN verification
- Password recovery
- Annual salary and income entry
- Tax deduction calculation
- Personal and family allowance management
- Tax calculation summary
- Tax history management
- Tax comparison between different years
- Pie chart visualization of tax data
- Multi-page desktop interface using CardLayout

## Technologies

- Java
- Java Swing
- Java AWT
- CardLayout
- JDBC
- MySQL (if applicable)
