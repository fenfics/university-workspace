# University Workspace
A collection of coursework completed throughout my Bachelor's degree in Computer Science at Kasetsart University. This repository contains laboratory exercises, programming assignments, mini projects, and final course projects from various computer science subjects.

## Repository Structure
```
university-workspace
├── C-Programming
├── Computer-Programming
├── Data-Structures
├── Computer-Architecture
├── Software-Construction
└── Introduction-to-Data-Science
```

## Contents
Each course may include one or more of the following:
- Laboratory exercises
- Programming assignments
- Mini projects
- Final course projects
- Practice programs
- Course materials and datasets

## Courses

### C Programming
Programming fundamentals using the C language, including algorithms, arrays, pointers, structures, file handling, and problem-solving techniques.

### Computer Programming
Introduction to Java programming, object-oriented programming, graphical user interface development, and programming exercises.

### Data Structures
Implementation and analysis of fundamental data structures and tree-based algorithms using Java.

### Computer Architecture
Assembly language programming and low-level computer architecture concepts, including memory operations and algorithm implementation.

### Software Construction
Object-oriented software development, Java Swing applications, software design principles, and larger programming projects.

### Introduction to Data Science
Data science fundamentals using Python, covering data preprocessing, exploratory data analysis, visualization, and machine learning algorithms. Labs and lecture notebooks organized into two sections:
- **`labs/`** — Lab assignments (Python basics, NumPy, Pandas, Matplotlib, EDA, KNN, Decision Tree, Association Rules)
- **`lectures/`** — Lecture practice notebooks (Seaborn, data mining, Apriori, data preparation)
